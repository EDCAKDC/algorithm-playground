# Algorithm Playground

A collection of **reusable algorithmic templates** with examples drawn from both general computer science and computational biology.

The repository began as algorithm practice and has expanded to include implementations relevant to bioinformatics problems such as clonotype grouping, genomic intervals, motif scanning, and graph-based single-cell analysis.

## Core Algorithm Templates

- breadth-first search (BFS)
- depth-first search (DFS)
- Union-Find / disjoint-set union
- interval merging
- sliding window
- prefix sums
- binary search
- heaps
- dynamic programming
- graph traversal and connected components

## Computational Biology Examples

### TCR / clonotype analysis

- exact clonotype grouping
- Union-Find-based clonal-family grouping

### Genomic intervals

- interval merge
- overlap detection
- union-peak construction
- peak annotation

### Sequence / regulatory analysis

- motif scanning templates

### Single-cell graphs

- toy k-nearest-neighbor graph construction
- BFS traversal
- connected-component clustering
- graph-based label propagation
- voting-based annotation propagation

## Purpose

The emphasis is on understanding and implementing core data structures and algorithms directly, then connecting them to computational-biology use cases where similar patterns occur in real analysis pipelines.
